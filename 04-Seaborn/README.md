# Seaborn 101

## 📖 Project Overview

This lab introduced the fundamentals of the Seaborn library for statistical data visualization in Python. Using a vehicle fuel efficiency dataset, I explored relationships between variables by creating several visualization types that support data exploration and interpretation.

The exercise focused on analyzing the relationship between the number of gears and a vehicle's combined MPG (miles per gallon) rating using multiple statistical plots.

---

## 🎯 Learning Objectives

- Learn the fundamentals of the Seaborn library.
- Create statistical visualizations using Python.
- Explore relationships between variables in a dataset.
- Interpret graphical representations of data.
- Apply visualization techniques to support data analysis.
