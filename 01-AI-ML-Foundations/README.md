# AI/ML Foundations

## 📖 Project Overview

This lab introduced the fundamentals of Artificial Intelligence (AI) and Machine Learning (ML) in cybersecurity through hands-on exercises using the TryHackMe platform. The activities explored how AI supports cybersecurity operations, the security risks associated with AI systems, and practical applications such as machine learning and log analysis.

---

## 🎯 Learning Objectives

- Understand the role of AI and Machine Learning in cybersecurity.
- Explore common AI and ML security threats.
- Learn how AI can be used to improve cyber defense.
- Complete practical exercises involving machine learning concepts.
- Analyze logs to identify security-related information.
