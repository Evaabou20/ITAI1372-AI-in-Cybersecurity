# Cybersecurity 101 - Fundamentals

## 📖 Project Overview

This lab introduced the core concepts and responsibilities of cybersecurity professionals through a series of hands-on exercises completed on the TryHackMe platform. The activities explored penetration testing methodologies, red team operations, hacker methodologies, and the responsibilities of a junior security analyst.

The completed submission contains screenshots demonstrating successful completion of all required TryHackMe rooms.

---

## 🎯 Learning Objectives

- Understand the cybersecurity lifecycle and common security functions.
- Learn the fundamentals of penetration testing.
- Explore hacker methodologies and ethical hacking concepts.
- Understand red team operations and engagement planning.
- Gain insight into the role of a Junior Security Analyst.
