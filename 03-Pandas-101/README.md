# Pandas 101

## 📖 Project Overview

This lab introduced the fundamentals of the Pandas library for data analysis in Python. Using a sample hiring dataset, I practiced loading, exploring, filtering, and analyzing tabular data while learning how Pandas supports cybersecurity workflows such as log analysis, data normalization, and anomaly detection.

The lab concluded with a coding challenge that required filtering a dataset and visualizing the results using a histogram.

---

## 🎯 Learning Objectives

- Learn the fundamentals of the Pandas library.
- Load and explore CSV datasets.
- Filter and manipulate DataFrames.
- Analyze structured data using Python.
- Visualize data with basic plots.
- Apply Pandas concepts to cybersecurity-related data analysis.
