# Course Capstone

## 📖 Project Overview

This capstone project documents the completion of the TryHackMe Advent of Cyber 2023 cybersecurity challenge, which served as the semester-long project for the course.

The project involved completing 20 hands-on cybersecurity labs covering a wide range of offensive and defensive security topics. Each completed task was documented with screenshots demonstrating successful completion.

---

## 🎯 Learning Objectives

- Apply cybersecurity concepts through hands-on exercises.
- Develop practical experience across multiple cybersecurity domains.
- Strengthen problem-solving and analytical skills.
- Gain experience using real-world cybersecurity tools and techniques.
- Demonstrate consistent progress through a semester-long security challenge.
