# ITAI 1372 – AI in Cybersecurity Portfolio

## 📖 Course Overview

This repository contains my coursework, hands-on labs, and semester projects completed for **ITAI 1372 – AI in Cybersecurity**.

Throughout the course, I explored the intersection of artificial intelligence and cybersecurity by completing practical exercises, machine learning labs, cybersecurity investigations, and semester-long projects. The portfolio demonstrates both technical skills and the ability to apply cybersecurity concepts in real-world scenarios.
